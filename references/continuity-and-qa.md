# Continuity and QA

## Review order

1. Hard facts: time, distance, injury, objects, resources, world rules
2. Causality: motive, means, consequence, and payoff
3. Knowledge access: who knows what, and when
4. Structure: scene function, pacing, repetition, escalation
5. Character voice: intent, diction, and behavior
6. Mechanics: punctuation, placeholders, duplicates, broken markup

## Common failures

- impossible travel or timing
- healed injuries with no on-page reason
- duplicated or vanished objects
- omniscient dialogue from a limited POV
- scenes that repeat function without escalation
- summary endings that flatten tension

## Fix rule

Repair the smallest upstream problem first. If the repair would change the ending, core cast, POV system, or world rule, ask the user before changing it.
