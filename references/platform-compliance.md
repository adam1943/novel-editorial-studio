## 立场

这一层的目标是让稿件真正符合平台规则，从而正常通过审核。不做规避审核的工作。

可以做：识别违规内容并改掉；调整过界的描写强度；修正格式与字数；提升文本质量以减少模板化痕迹。

不做：把违规内容伪装成合规形态；用错别字、拆字、谐音、异体字、零宽字符、图片替换等手段绕过关键词过滤；伪造原创声明或规避平台的AI内容披露要求。

遇到用户要求规避审核时，说明这一条边界，然后给出合规路径：把内容改到真正达标。

## 硬红线

以下内容直接判 block，必须删改，不做技术性变形：

- 涉及未成年人的性化描写或性暗示
- 露骨性行为描写
- 详细的自杀、自残、制毒、制爆方法
- 违禁品交易的可操作细节
- 民族、宗教、地域、性别、残障群体的侮辱与仇恨内容
- 现实政治敏感议题、真实国家机构与在世公众人物的负面虚构
- 现实可识别的真实人物、真实品牌的不当关联
- 抄袭与洗稿：不得改写他人作品作为自有内容

## 需要改写的高风险表达

这些不一定违规，但按平台惯例容易被拦，默认降强度：

| 类型 | 处理 |
| --- | --- |
| 暴力血腥 | 保留后果与代价，删解剖级细节 |
| 亲密戏 | 停在门口，用留白与转场 |
| 犯罪手法 | 只写结果与动机，不写可复制步骤 |
| 赌博与药物 | 只作情节背景，不写具体操作与配方 |
| 自杀自伤 | 不写方法，加入干预或后果视角 |
| 医疗与法律细节 | 避免给出可执行建议 |
| 现实地名机构 | 架空化或模糊化处理 |

## 平台格式基线

按番茄类平台的常见要求设默认值，项目可在总控覆盖：

- 单章 2000 到 3000 字，长期稳定不要大幅波动
- 章标题简短，不带营销语和特殊符号
- 段落短，多用换行，避免长段堆砌
- 使用中文标点，对话用引号，不用大量特殊符号与颜文字
- 不在正文里出现作者的话、外链、联系方式、平台名互推
- 不出现占位符、未替换的模板文字、乱码
- 章号连续，无跳号与重号

## 署名与AI标注

如果平台要求披露AI辅助创作，按平台规则如实标注。不要为了规避标注而隐瞒创作方式。这项由用户决定并承担，技能只提示，不代替用户操作发布。

## 合规检查流程

1. 跑 `scripts/compliance_scan.py` 做关键词与格式初筛。
2. 按硬红线逐条人工核，命中即改内容本身。
3. 按高风险表清单降强度。
4. 校对格式基线。
5. 把判定写进审计记录；无法在不损坏剧情的前提下改写时，停机报人并给出两到三种改写方案。

脚本只提供线索，最终判定由审计员完成。命中数不等于违规，未命中也不等于安全。
