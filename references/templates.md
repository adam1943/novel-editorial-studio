# Templates

## 项目总控.md

- 作品名
- 类型 / 卖点
- 目标读者
- 视角与时态
- 篇幅预期
- 主题问题
- 叙事规则
- 禁区
- 事实权威顺序

长篇连载追加这些字段，缺任何一项都不要开自动档：

| 字段 | 示例 |
| --- | --- |
| 目标总字数 | 2000000 |
| 单章字数区间 | 2200-2800 |
| 每批章数 | 5 |
| 卷数与卷字数 | 8 卷，每卷约 25 万字 |
| 主角人设锁 | 强势冷静、能忍能杀、不圣母 |
| 战力或等级上限 | 最高第九境，第 700 章前后到达 |
| 资源单位与上限 | 灵石、血脉浓度，上限写明具体数值 |
| 结局方向 | 一句话写清终局状态 |
| 禁令清单 | 关键时刻心软、配角喧宾夺主、无意义暧昧拖节奏 |
| 疲劳词覆盖 | 项目自定义词表 |
| 质量门阈值 | block=0，warn<=3 |
| 合规基线 | 目标平台与格式要求 |
