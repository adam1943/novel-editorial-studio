## 使用方式

开书时选一个题材，把对应规则复制进项目总控，然后按项目需要改。项目总控里的写法优先于本文件。

每个题材需要落这几项：升级或推进机制、节奏单位、禁忌清单、疲劳词、启用的审计维度。

## 玄幻与仙侠

推进机制：等级或境界阶梯，配资源与代价。必须在总控写死最高层与到达章节。

节奏单位：受压 -> 获取 -> 训练或代价 -> 反制 -> 收益兑现。收益要落到具体场面，不只写“地位提升”。

禁忌：无来源的越级战胜；反派无理由等待主角成长；关键时刻圣母心；同质吞噬无衰减导致数值失控。

疲劳词：瞳孔骤缩、不可置信、气息一沉、深不可测、轰然一声。

启用维度：全部。

## 都市

推进机制：资源、人脉、信息差、制度约束。不使用数值系统。

节奏单位：目标 -> 阻力 -> 交换或博弈 -> 代价 -> 局势变化。

禁忌：靠巧合解决核心冲突；法律与流程明显失真；年代物件与用语错位；主角无成本获得权力。

疲劳词：淡淡一笑、眼神一冷、气场全开。

启用维度：关闭数值与战力，增加年代与常识考据。

## 悬疑与恐怖

推进机制：信息释放节奏与恐惧层级递进。

节奏单位：异常 -> 试探 -> 误判 -> 逼近 -> 揭露一角。

禁忌：过早全揭；用解释消灭恐惧；靠形容词代替具体异常；侦探靠灵感直接得出结论。

疲劳词：诡异、莫名的恐惧、毛骨悚然、说不出的压迫感。

启用维度：关闭数值，强化信息控制、视角一致性与氛围递进。

## 言情

推进机制：关系状态迁移与误解-澄清循环。

节奏单位：靠近 -> 试探 -> 阻力 -> 让步或撤退 -> 关系变化。

禁忌：升温无事件支撑；反复同一误会；配角只为制造矛盾存在；情绪靠形容词堆砌。

疲劳词：心头一颤、莫名的悸动、鼻尖萦绕。

启用维度：关闭数值，强化情感弧线、关系热度与台词真实度。

## 语言铁律

所有题材共用，写手与审计员同时执行。

- 状态用体感与动作呈现，不报数字：不写“力量从12提升到24”，写“握拳时指骨发紧”
- 情绪用行为呈现，不贴标签：不写“他感到恐惧”，写“他把钥匙插了三次才对上锁孔”
- 不在正文使用分析术语：核心动机、信息落差、状态变化、人物弧光
- AI 标记词限频：仿佛、忽然、竟然、不禁、宛如、猛地，每 3000 字合计不超过 3 次
- 同一意象连续渲染不超过两轮
- 叙述者不替读者下结论
