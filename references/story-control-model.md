# Story Control Model

## Truth layers

- Stable lore: rules that should not drift with the plot
- Dynamic events: changes over time
- Future plan: intended but not yet true
- Prose: the rendered chapter text

## Plot model

Use two trees.

- Carrier tree: story -> volume -> chapter -> scene
- Causal tree: story -> phase -> plotline -> scene

Let the scene sit at the intersection of structure and causality.

## Scene card

Record for each scene:

- purpose
- POV character
- time and place
- present characters
- scene result
- state changes
- information control
- foreshadowing or payoff
- forbidden knowledge

## Writing package

Before drafting a batch, compile:

- current project control
- relevant world state
- prior scenes that matter
- scene-by-scene targets
- do/don't constraints
- unresolved questions

## Change rule

Every scene must change at least one state: information, power, relationship, resource, risk, or decision.
